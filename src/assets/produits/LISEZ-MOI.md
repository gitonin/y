# Visuels des produits

Déposez ici les photographies des packagings, une par référence.

## Comment déposer

Depuis GitHub, sur la branche `claude/yunma-site-v4` :
**Add file → Upload files**, ou directement par ce lien :
<https://github.com/gitonin/y/upload/claude/yunma-site-v4/src/assets/produits>

Déposer un fichier sous un nom déjà présent le remplace : rien d'autre n'est
à modifier, le site reprend le nouveau visuel au déploiement suivant.

## Nommage attendu

| Fichier                       | Produit                            |
| ----------------------------- | ---------------------------------- |
| `torch-estate-lot-01.jpg`     | Torch Estate, Lot 01 — 200 g       |
| `torch-estate-lot-02.jpg`     | Torch Estate, Lot 02 — 200 g       |
| `yun-lan-estate.jpg`          | Yun Lan Estate — 200 g             |
| `sachet-filtre-catimor.jpg`   | Gaosheng — Catimor, étui de 5      |
| `sachet-filtre-bourbon.jpg`   | Gaosheng — Bourbon jaune, étui de 5|
| `offre-decouverte.jpg`        | Offre Découverte                   |

Un nom différent ne pose pas de problème : il suffit de préciser à quelle
référence correspond chaque fichier.

## Format

- Cadrage **carré**, 2000 × 2000 px au minimum
- **JPEG, qualité 90** : la photographie remplit la tuile du catalogue de bord
  à bord, c'est donc elle qui porte le fond
- **Le même décor d'une référence à l'autre** : côte à côte dans la grille,
  deux ambiances différentes se voient
- Les fichiers d'origine, pas des versions réduites : le site fabrique
  lui-même toutes les tailles dont il a besoin
